# 中医药智能问答系统

这是一个基于知识图谱的中医药问答系统，旨在通过自然语言处理和语义网技术，为用户提供关于中药方剂和药品的智能问答服务。

## ✨ 项目特色

*   **自然语言查询**：用户可以使用日常语言提出问题，例如“补血和气饮可以治疗什么病症？”或“如何制作苍术难名丹？”。
*   **知识图谱驱动**：后端利用 RDF 知识图谱存储中医药知识，通过 SPARQL 查询语言精确检索答案。
*   **广泛的问题覆盖**：系统支持多种类型的问题，包括：
    *   **中药方剂**：制作处方、功能主治、用法用量、注意事项、制作方法和临床应用。
    *   **中药药品**：功能主治、用法用量和注意事项。
*   **Web 界面**：提供一个简洁直观的 Web 界面，包含示例问题，方便用户上手。
*   **备用方案**：对于无法解析或知识库中不存在答案的问题，系统将引导用户至大型语言模型（如文心一言）进行查询。

## 🛠️ 技术栈

*   **后端**：Flask, rdflib
*   **前端**：HTML, CSS, JavaScript
*   **数据格式**：Turtle (.ttl) for RDF graph
*   **查询语言**：SPARQL

## 📂 项目结构
```bash

中医问答-终/
├── 中医问答/

│       └── 大作业.py                 // Flask 应用主文件

```

## 🚀 如何运行

1.  **安装依赖**:
    确保您已安装 Python。然后通过 pip 安装所需的库：
    ```bash
    pip install Flask rdflib
    ```

2.  **启动应用**:
    进入 `中医问答/4.sqarql+flask/` 目录，并运行 `大作业.py` 文件：
    ```bash
    cd "中医问答/4.sqarql+flask"
    python 大作业.py
    ```

3.  **访问系统**:
    打开您的浏览器并访问 `http://127.0.0.1:5000` 即可开始使用。
